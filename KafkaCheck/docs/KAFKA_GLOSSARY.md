# Словарь терминов Kafka

## Базовые термины

| Термин | Описание |
|--------|----------|
| **Broker** | Сервер Kafka, хранит сообщения и обрабатывает запросы |
| **Topic** | Категория сообщений (аналог таблицы в БД) |
| **Partition** | Часть топика для параллельной обработки |
| **Offset** | Номер сообщения в партиции |
| **Replication Factor** | Количество копий партиции |

## Producer

| Термин | Описание |
|--------|----------|
| **Producer** | Приложение, отправляющее сообщения |
| **Acks** | Уровень подтверждения: `0` (без подтверждения), `1` (лидер), `all` (все реплики) |
| **Batching** | Накопление сообщений для отправки пачками |
| **Compression** | Сжатие: `gzip`, `snappy`, `lz4`, `zstd` |

## Consumer

| Термин | Описание |
|--------|----------|
| **Consumer** | Приложение, читающее сообщения |
| **Consumer Group** | Группа consumer'ов, читающих один топик совместно |
| **Commit** | Сохранение текущего offset |
| **Rebalancing** | Перераспределение партиций между consumer'ами |
| **Lag** | Отставание consumer от последних сообщений |

## Репликация

| Термин | Описание |
|--------|----------|
| **Leader** | Главная реплика партиции |
| **Follower** | Копия, синхронизирующаяся с лидером |
| **ISR** | In-Sync Replicas — актуальные реплики |

## Архитектура

| Термин | Описание |
|--------|----------|
| **KRaft** | Современный режим без Zookeeper (Kafka >= 3.3) |
| **Zookeeper** | Legacy режим с внешним координатором |
| **Controller** | Брокер, управляющий метаданными кластера |

## Стратегии ребалансировки

| Стратегия | Описание |
|-----------|----------|
| **range** | Последовательное назначение партиций |
| **roundrobin** | Равномерное чередование |
| **sticky** | Минимизация перераспределения |
